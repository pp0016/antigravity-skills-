## How Patterns Are Added

1. User uploads a competitor transcript
2. Skill scans for human writing patterns AI + humanizer can't produce
3. Skill filters — only truly exceptional, novel patterns pass
4. Pattern is appended below with full metadata
5. All future audits use these patterns alongside the base 17

## Quality Gate Criteria

A pattern is only added if ALL of the following are true:
- It is NOT already covered by the 17 base patterns in pattern_library.md
- It is genuinely different from existing learned patterns
- It has a specific, reproducible mechanism (not just "good writing")
- It includes a real example from the source transcript
- Adding it would make future script audits measurably sharper
