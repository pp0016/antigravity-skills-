# Two-Pass Script QA Checklist

> Run this checklist AFTER /humanizer (Pass 1). This is Pass 2 — the structural audit.

## Pre-Check: Has /humanizer Been Run?

Before starting Pass 2, verify Pass 1 (surface cleanup) is complete:
- [ ] Em dash overuse removed
- [ ] AI vocabulary words replaced (delve, tapestry, testament, vibrant, multifaceted, etc.)
- [ ] Rule-of-three patterns broken
- [ ] Passive voice reduced
- [ ] Promotional/inflated language stripped
- [ ] Filler phrases removed

If any of these are still present, send the script back to /humanizer first.

---

## Binary Pre-Flight: 12 Anti-Slop Gates (Go/No-Go)

> These are BINARY checks — pass or fail. If ANY gate fails, fix it before running the scored audit below.

- [ ] **1. ZERO-THROAT-CLEARING:** Topic noun appears within first 1.5 seconds. No greetings, no rhetorical questions.
- [ ] **2. TACTILE HOOK ANCHOR:** Hook contains at least one concrete physical texture/material (not abstract adjective).
- [ ] **3. SOURCE DENSITY:** ≥8 named sources per 1,000 words. Zero "studies show" / "historians argue."
- [ ] **4. DRAMATIZED SOURCES:** Every source introduced as a scene with location, not a bibliography footnote.
- [ ] **5. REGISTER COLLISION:** ≥3 moments where modern slang collides with formal subject matter.
- [ ] **6. READING LEVEL:** Flesch-Kincaid Grade 7.0-12.0. Average sentence length <14 words.
- [ ] **7. WPM MODULATION:** Action sections at 165-180 WPM, trauma/dread sections at 130-140 WPM.
- [ ] **8. ZERO-FILLER TRANSITIONS:** No "Next up", "Moving on", "Now let's look at." Hard cuts, title drops, or causal questions only.
- [ ] **9. EMBODIED NARRATOR:** Narrator reacts as a human ≥1x per segment (sarcasm, shrug, "you", fourth-wall).
- [ ] **10. OPEN LOOP TENSION:** Each segment ends on unresolved tension, not a resolved summary.
- [ ] **11. A/B/C DEPTH RANKING:** Items have visibly different lengths. No democratic equal-time allocation.
- [ ] **12. SUB-5-SECOND OUTRO:** Script cuts to silence within 3-5 seconds of final punchline. Zero recap, zero CTA.

**Gate result:** ___/12 passed. If <12, fix failures before proceeding to scored audit.

## Execution Order

When running this checklist, follow this order (dependencies matter):

1. **First:** Check 11 (Editorial selectivity — decide A/B/C weighting before detailed checks)
2. **Then:** Check 12 (Cold open) and Check 5 (Segment openings)
3. **Core body:** Checks 1, 3, 14, 17 (Research depth + source treatment + sensory grounding + readability)
4. **Rhythm layer:** Checks 15, 9 (Micro-loops + oral rhythm)
5. **Personality layer:** Checks 2, 4, 6, 8 (Whiplash + register collision + embodiment + courage)
6. **Comprehension:** Checks 7, 10 (Transitions + pop culture anchoring)
7. **Retention:** Check 16 (Open loops — verify forward tension exists)
8. **Final:** Check 13 (Outro — verify it's sub-5 seconds)
