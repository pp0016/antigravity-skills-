SRT Whiteboard · Region Editor
Click Open Folder… and select the directory containing your line-art scene images and paired annotations (matching <name>.png + <name>.annotation.json).

Workflow:
• Canvas: Drag boxes to reposition. Drag corners or edges to resize each region.
• Sidebar: Adjust names, reveal directions, Start / End times (ms), and associated subtitles.
• Reordering: Drag items in the element list to reorder drawing sequence (auto-updates sequence).
• Playback: Drag timeline or click Play to preview proxy reveals (unstarted regions remain hidden).

Click Save Scene or Save All to write updates back to the .annotation.json files.
Note: Direct disk saving requires Chrome or Edge (File System Access API). Other browsers will download files for manual replacement. Full video rendering is performed via CLI using render_stream_whiteboard.py.
